# Submission package

This package is prepared for a coordinator review. It does not submit any competition form or contact organizers.

## Included

- Open-source repository with MIT license and setup instructions.
- Requirements source log, matrix, ambiguity register, and adversarial preflight.
- Product and architecture decision documents.
- Deterministic seed/reset demo with local persistence.
- Admin, evaluator, speaker portal, public CFP, public schedule, public gallery, API docs, and health surfaces.
- Focused domain tests, Chromium judge journey, visual screenshots, verification, accessibility, performance, security, deployment, cost, and limitations reports.

## Claims boundary

The package claims local functional behavior and dry-run provider seams where direct evidence exists. It does not claim live Cloudflare, Airtable, R2, Accelevents, or email readiness; those remain blocked pending a separately authorized release target and credentials. The competition entry form remains intentionally unsubmitted.
