## Blockers To Carry Forward

- Exact public CFP runtime field schema is blocked for this lane because the public URL serves a static SPA shell without field data.
- Discord pinned/current update content is blocked without authenticated read access. The invite metadata confirms the community exists but does not expose updates.
- Live Accelevents verification is blocked until sandbox credentials and a safe test event exist.
- Live email/calendar delivery verification is blocked until allowlisted recipients and provider credentials exist.
- Cloudflare/Airtable/R2 live proof is blocked until root/release confirms safe dedicated resources and credentials.

## Implementation Bias

When a feature can be implemented several ways, choose the smallest workflow-complete behavior that demonstrates real event operations: public CFP to admin record, review, acceptance, speaker onboarding, realtime dashboard, schedule/conflict, communications/calendar, public schedule/gallery. Exact Sessionboard screen fidelity is lower priority than persistence, authorization, evidence, and repeatable demo reset.
